# Project context

The default YouTrack project for task management is [TM](https://scentblend.youtrack.cloud/projects/TM). Use it for issue searches and creation unless the user specifies another project.

[SB_CUST](https://scentblend.youtrack.cloud/projects/SB_CUST) is an experimental knowledge base for customers. Do not use it for tasks.

Business identity (legal entity, IČO, services, e-shop, public references) is in [company/identity.md](company/identity.md). Read it before working on anything customer- or company-facing.

Before searching Google Drive, read [systems/google-drive.md](systems/google-drive.md). It maps each folder to its purpose and folder ID.
