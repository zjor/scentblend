## Fields

| Field | Meaning |
| --- | --- |
| Name | Full name, as written in contracts |
| Called | Short name the team uses |
| Role | Job title |
| Type | `Core` or `Brigádník` (part-time worker) |
| Status | `Active` or `Former`; keep former members for history |
| Work email, Personal email, Phone, Telegram | Contacts; leave empty when unknown |
| Agreements | Links to signed files in Drive (DPP = dohoda o provedení práce) |
